```
入校試用紀錄/
├── 原始資料/                       # 全部原始檔案
│   ├── 自然科/ 數學科/ 英語科/    # 拆分後的訪談逐字稿（依日期×學校×組別）
│   ├── 115入校試用逐字稿紀錄.md   # 原始合併檔（拆分前）
│   ├── ELAINE筆記                  # 同事入校觀察（03-17 海山）
│   └── 問卷備注                    # 跨校學生匿名問卷開放欄位
└── _分析/
    ├── 中介筆記/                   # 第一階段：每場訪談／來源一份結構化筆記
    │   ├── 自然科/ 數學科/ 英語科/
    │   └── _問卷/                  # 跨校問卷整理
    ├── 主題-功能/                  # 第二階段：依功能模組合併
    ├── 主題-跨議題/                # 第二階段：依跨功能議題合併
    ├── 主題-科別專屬/              # 第二階段：科別差異
    └── 彙整/                       # 第三階段：兩種輸出 + 本索引
```

> **資料存放與隱私**
> - 原始音檔、問卷分析、逐字稿等**含真實學生姓名的原始資料僅存於本機**，未發布到公開 repo（已自版控與 git 歷史移除）。
> - 最完整的逐字稿母本為 repo 外的 `逐字稿整理版/*.txt`（含完整對話、辨識修正對照表、受訪者資訊）；`原始資料/*.md` 為分析時使用的濃縮版，部分經改寫——**內容以 .txt 母本為準**。
> - 因原始資料不發布，下方各中介筆記的「來源檔」連結為**本機參照**，線上不可點。

## 引用格式公約

- 不寫學生姓名或代號（「學生1」「婉晴」等不出現）
- 老師訪談保留標題上的姓名（如「楊宗榮老師」），內文不再點名
- 同事觀察員身分以「**觀察員**」標示；跨校問卷以「跨校學生問卷（匿名）」標示
- 原句節錄 1–3 句，可用「……」省略中段
- 以章節結構標示來源（學校→角色），不在原句後再附人名
